# Astra Dental Schema Markup

Private repository for Astra Dental Centre structured data files, schema templates, and implementation notes.

Website: https://astradentalcentre.com/

## Purpose

This repository is used to organize and back up schema markup for Astra Dental Centre, including:

- LocalBusiness schema
- Dentist schema
- FAQ schema
- Review schema
- Service schema
- Breadcrumb schema
- BlogPosting schema
- WebPage schema
- Organization schema
- Schema testing notes
- Published schema backups
